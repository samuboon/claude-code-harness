# Privacy Policy

Last updated: 2026-09-18

This policy covers the Jira Cloud apps listed on the Atlassian Marketplace by
this developer (referred to below as "the apps"). The apps are documented in
[README.md](README.md).

## 1. What the apps run on

The apps are built on Atlassian Forge. Their code is hosted and executed by
Atlassian on Atlassian infrastructure. The developer does not operate any
server, database, or analytics service that receives data from your Jira site.

## 2. What the apps read

The apps read only the Jira data needed to answer the request that is being
made at that moment: issue fields, sprint records, project roles, remote issue
links, and the app's own configuration. The scopes each app requests are
declared in its manifest and are shown to you before you install it.

## 3. What the apps store

Configuration that you enter on the app's admin page (for example a holiday
calendar or a date format) is stored using Atlassian's Forge storage, inside
Atlassian's infrastructure, scoped to your site. Some apps write an index of
your own issue data back onto your own issues as issue properties. Nothing is
stored outside Atlassian.

## 4. What leaves your site

Nothing. The apps make no outbound network calls to the developer or to any
third party. They do not use analytics, tracking, advertising, or profiling.

## 5. Support

If you contact support, the developer receives the message and any details you
choose to include in it. That correspondence is kept only for as long as needed
to answer you, and is not used for any other purpose.

## 6. Data residency, retention and deletion

Because all data stays inside your Atlassian site, Atlassian's own data
residency and retention terms apply. Uninstalling an app removes its Forge
storage. Issue properties written by an app can be removed on request.

## 7. Changes

If this policy changes, the date above changes with it.

## 8. Contact

Questions about this policy, or a request to remove issue properties written by
an app: open an issue at
https://github.com/samuboon/claude-code-harness/issues, or use the support
contact shown on the app's Marketplace listing.
